# SunFly Club

Статичний сайт студії: `index.html`, `schedule.html`, `spa.html`, спільні `css/style.css` та `js/script.js`. Збірка та встановлення залежностей не потрібні. Всі локальні шляхи відносні й працюють у підкаталозі GitHub Pages.

## Локальний перегляд

У корені проєкту запустіть `python -m http.server 8000` і відкрийте `http://localhost:8000/`. Перевіряйте всі три сторінки, а також переходи `index.html#gallery`, `#services` і `#contacts`.

## Перевірка перед релізом

- Перегляньте сторінки на телефоні та широкому екрані; перевірте меню, зміну орієнтації, Escape і повернення браузером назад.
- Перевірте збільшення фото та розкладу клавішами Tab / Enter / Escape і повернення фокусу після закриття.
- Перевірте стрілки, точки, паузу та горизонтальний свайп SPA-слайдера. Вертикальна прокрутка не повинна перемикати зображення.
- Увімкніть зменшення руху в налаштуваннях пристрою; автоматичне перемикання слайдів має зупинитися.
- Перевірте кнопки запису: вони телефонують на `+380 67 499 94 99`.
- Перевірте доступність Instagram та інтерактивної Google Maps з мережі відвідувача.
- Підтвердьте актуальність розкладу, цін SPA та переліку послуг. На сторінці SPA наразі використані фотографії спортивного залу — потрібні справжні фото SPA.

## GitHub Pages

У репозиторії вже є успішне розгортання GitHub Pages для `main` від 31.07.2026. Для наступного оновлення збережіть поточне джерело публікації; окремий процес збірки не потрібний. Після злиття перевірте виконання **pages build and deployment**, відкрийте опубліковані три сторінки та повторіть перевірку запису, зображень, меню й зовнішніх посилань. Створення pull request саме по собі не оновлює сайт.

## Аудит 06.10.2026

Виправлено заглушки Telegram, видимість контенту без JavaScript, доступність перегляду зображень, стан мобільного меню при переході до широкого екрана, зміщення якорів під навбаром, паузу та зменшення руху для слайдера, фільтрацію вертикальних і скасованих свайпів, основний заголовок та навігаційні ARIA-атрибути. Видалено невикористані `.header-top`, `--accent-gradient` і невикористану змінну `slides` у свайпі.

Перевірено в Chrome всі три сторінки на ширинах 320, 390, 768, 860, 861, 1024 та 1440 px, мобільну навігацію без JavaScript, зменшення руху, клавіатурне керування модальним переглядом і 54 локальні посилання на ресурси та секції. На перевірених ширинах немає горизонтального переповнення або помилок JavaScript. Safari, Firefox, фізичні сенсорні пристрої та фактичний дзвінок не перевірялися.

Подальші покращення: текстова версія розкладу для читачів екрана, оптимізація великих `logo.png` і `schedule.png`, абсолютний URL для Open Graph після підтвердження публічної адреси. Непідключений `images/favicon/site.webmanifest` має порожню назву й абсолютні шляхи іконок; перед підключенням його потрібно виправити.
